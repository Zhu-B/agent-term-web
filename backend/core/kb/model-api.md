# F 模型与接口(LLM 通道)

「图进不了模型视野/参数设了像没设/型号名骗人」这一类. 前提认知:
**兼容端点各家实现有差异, 型号标签不可信, 一切以实测为准**(见也 [[claude-code-model-backend]] 惯例).

---

### F1 图怎么进模型: tool 角色内嵌图无文档支持 → 在 tool 块后注入合成 user 消息

- 现象: tool 结果里带图, 模型看不到 / 端点报错.
- 根因: 主流官方文档只文档化 **user 消息**里的 image_url 内容块; **tool 角色内嵌图
  两家都无文档支持**.
- 对策: 发送视图每次请求**现造**: 连续的 tool 块之后注入一条合成 user 图像消息
  `[{text:"(工具返回的图像)"}, {image_url: data-URI}]` —— 保持
  assistant(tool_calls)→tool×N→user(图) 结构合法; canonical messages 永不动
  (切模型/中转自适应, resume 可重建). 加大小闸(单图/每轮张数), 非视觉档剥引用留"已略过"注记.
- 出处: agent-term vision.py(2026-10-13, 智谱/DashScope 文档定案).

### F2 型号标签不可信: 同名不同命, 以实测为准

- 实例: `qwen-vl-max` 在该兼容端点 404, `qwen3-vl-plus` 正常; 标着某家的名字实际是
  另一家的模型(端点直连换挂).
- 对策: 接新模型先发**最小探针请求**(一图一问/一句话), 通了再进配置; 挑档时优先看
  实测行为(支不支持工具调用/视觉)而不是名字; 404 就换型号姿势重试, 别硬扛.
- 出处: agent-term M0/M15(2026-09-30/10-13); claude-code-model-backend 记忆.

### F3 同名参数跨家语义不同

- 实例: 思考档位(effort)三家语义分裂 —— 有家是真旋钮、有家等于关思考、有家参数纯装饰
  (预算类参数甚至改了没影响).
- 对策: 调参实验前先跑**旋钮探针**(同题三档对比, 看行为是否真变), 别信参数名;
  agent-term 里给用户解释某参数时也先实测.
- 出处: 申博实验 G 旋钮波(2026-09).

### F4 falsy 参数被丢弃(0/False 存不进去)

- 现象: 配置里显式关掉的能力(如 vision=0)保存后再读变成"没这字段".
- 根因: 存配置链路里 `if value:` 之类筛掉了 falsy(`add_model` 丢 falsy 的既有行为).
- 对策: 真值统一用 `1`(而不是 True); 关=不存字段, 读取侧默认 False; 或在链路里显式保留.
- 出处: agent-term models.json 能力位(2026-10-13).

### F5 API 400 消息配对: tool_calls 与 tool 结果必须一一配对

- 现象: 中断/异常后下一轮请求 400.
- 根因: assistant 的 tool_calls 里有的 call_id 没有对应的 tool 结果消息(中断留的孤儿).
- 对策: **消息铁律** —— 每个 tool_call_id 必须有且仅有一条回填; 中断/失败也要补占位结果
  ("未回/中断"说明), 绝不留下孤儿 call; 断开(abort)后复位状态机防"永不复位".
- 出处: agent-term agent.py(2026-10-13, 中断孤儿 call 400 洞 + abort 复位修复).
